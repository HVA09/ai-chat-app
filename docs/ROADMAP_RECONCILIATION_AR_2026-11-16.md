## 1. الخلاصة التنفيذية

1. مراحل A–G توثق بناء الأساس الإنتاجي وتجربة المنتج وقدرات Agent وDeveloper Ecosystem وWorkspace والإصدار الأول. اكتمال بند تاريخي لا يعيد إثبات إعدادات Render الحالية أو قبول الهاتف أو الإنتاج في 16 نوفمبر.
2. خارطة ما بعد G تسجل H مفتوحة وI نشطة. هذا يتفق مع الوضع الحالي: إصلاحات مهمة للبث واتصالات قاعدة البيانات وسلامة Agent دُمجت، لكن بوابات Stage وAndroid وUX لم تُغلق.
3. J–T مراحل مستقبلية/مخططة. لا تُحوّل إلى قائمة تنفيذ نشطة قبل إغلاق H/I أو اعتماد أولوية مبنية على قياس وحاجة.
4. PR #665 ما زال Draft وغير مدمج؛ لا يُدمج ككتلة واحدة. أجزاء من نطاقه دخلت main عبر PRs أصغر، ويجب استبعادها من أي استخراج جديد.
5. PR #671 أُغلق دون دمج لأنه مبني على Base قديم؛ ملفاه محفوظان في الأرشيف المركزي. PR #716 هو سجل المتابعة الأحدث المدمج، وليس دمجًا لـPR #665.

## 4. ما تغير فعلاً على main حتى 16 نوفمبر

### 4.1 قاعدة البيانات والبث — لا تكرر التنفيذ

- PR #664 — [release DB connection before chat SSE waits](https://github.com/HVA09/ai-chat-app/pull/664) — مدمج عند `0fd0f7cb9edeb3fabf3c3f8e22792ce8a069b5a2`.
- PR #676 — [release pool connections before external waits](https://github.com/HVA09/ai-chat-app/pull/676) — مدمج عند `35b1d3bd856590cd2648903922a4acff7573edf5`.
- يحسن الاثنان حد المعاملة ويحرران checkout قبل I/O الخارجي ضمن نطاقهما. لا يعني الدمج أن ضغط Pool التشغيلي اختفى؛ Issue #674 تبقى مفتوحة لمراقبة Stage وتحديد مصدر أي timeout جديد.
- لا ترفع `DATABASE_POOL_SIZE` أو `MAX_OVERFLOW` أو مهلة الانتظار اعتمادًا على حادثة واحدة؛ اربط checkout/wait/timeout بمعرفات الطلبات والجلسات وافحص pooler الخارجي.

### 4.2 Agent tool/retry safety

- PR #687 — [prevent duplicate side effects on retry](https://github.com/HVA09/ai-chat-app/pull/687) — مدمج عند `be1700b006db493ef6b495dd7952da5a8fcab56c`.
- يمنع retry غير الآمن بعد بدء Tool أو عند غموض نتيجة النقل، ويكشف pseudo-call النصي عندما لا يصل structured tool call.
- هذا يغلق جزءًا من مشكلة عرض/إعادة تنفيذ الأدوات ضمن Issue #683، لكنه لا يغلق إصلاحات Sidebar أو message actions أو Composer أو قبول Android أو تشخيص فشل المزود.

### 4.3 تفكيك Embeddings/RAG وملفات المعرفة

- PR #665 الأصلي ما زال **Open + Draft + Unmerged**؛ فرعه الكبير ليس أساسًا صالحًا لدمج جماعي.
- سجل التفكيك في `docs/PR-665_SPLIT_TRACKER_AR.md` هو المصدر المحلي للتمييز بين ما دخل main وما بقي.
- PRs #692 و#694 و#695 و#696 مدمجة بحسب سجل التفكيك. استبعد هذه النطاقات من أي استخراج جديد.
- لا تُعد استخدام Alembic revision `0081` الذي أصبح مستخدمًا في main؛ بصمات الملفات جاءت بعده في revision `0082`.
- الملفات القديمة قد تملك fingerprints فارغة؛ لا backfill أو إعادة فهرسة جماعية قبل backup/restore موثوق وdry-run ومراجعة الصلاحيات.
- التقييم المقترح محلي/offline على بيانات اصطناعية؛ لا تستخدم `--run-live` ولا تستهلك حصة مزود قبل موافقة منفصلة.
