# AI Assistant Frontend

واجهة شات لمساعد ذكاء اصطناعي — React + Vite + Tailwind CSS + i18next (عربي/إنجليزي، RTL/LTR).

## المزايا

- تسجيل دخول / إنشاء حساب (JWT، متوافق مع الباك اند)
- نسيت كلمة المرور + صفحة إعادة تعيين (عبر رابط بالإيميل)
- صفحة تأكيد البريد الإلكتروني (عبر رابط بالإيميل)
- لوحة "الحساب" (من رأس الصفحة): الملف الشخصي، تغيير كلمة المرور، تأكيد البريد، تفعيل/تعطيل 2FA بـ QR code، حذف الحساب
- لوحة "الملفات": سحب وإفلات، شريط تقدّم، معاينة الصور وPDF، تحميل، حذف
- لوحة "الإدارة" (تظهر فقط لحساب admin): إحصائيات مع رسوم بيانية (مستخدمون، محادثات،
  توكنز AI لآخر 30 يوم) وتصدير CSV، إدارة المستخدمين (تفعيل/تعطيل/ترقية/حذف)،
  إدارة كل المحادثات، وسجل تدقيق للأحداث المهمة
- لوحة "الاشتراك": عرض الخطط، الاشتراك عبر Stripe/PayPal (تحويل لصفحة الدفع)، إلغاء الاشتراك
- جرس إشعارات بالهيدر: تنبيهات فورية عبر WebSocket (تفعيل/إلغاء اشتراك، قفل حساب...)
  + قائمة سجل كاملة تُقرأ عند الفتح
- أداء: تحميل كسول (lazy) لكل لوحة (الحساب/الملفات/الإدارة/الاشتراك) — كل وحدة ملف
  منفصل ما يُحمَّل إلا عند فتحها؛ وقائمة المحادثات تتحول لـ virtual list تلقائيًا
  لو تجاوزت 30 محادثة (أداء أفضل لقوائم طويلة)
- PWA: قابل للتثبيت كتطبيق (manifest + service worker تلقائي عبر vite-plugin-pwa) —
  أيقونات placeholder جاهزة بـ `public/`، استبدلها بشعارك الحقيقي متى حبيت
- SEO أساسي: meta description وOpen Graph بـ index.html، robots.txt، sitemap.xml
  (حدّث الدومين بـ sitemap.xml بعد النشر)
- تسجيل الدخول يدعم رمز 2FA تلقائيًا لو الحساب مفعّل عليه
- شات مع حفظ سياق المحادثة (`conversation_id`)، والرد يوصل تدريجيًا (streaming) مثل ChatGPT
- قائمة جانبية بمحادثاتك الحقيقية: عرض، إعادة تسمية، حذف
- عرض Markdown وتلوين أكواد داخل الردود
- عربي/إنجليزي + RTL/LTR تلقائي

## التشغيل

```bash
npm install
npm run dev
```

يفتح على `http://localhost:5173`.

## الربط بالباك اند

- `.env.development` فيه `VITE_API_BASE_URL=http://localhost:8000` — يفترض إن الباك اند
  شغّال محليًا عبر `docker compose up` (راجع README الباك اند)
- `.env.production` فيه placeholder — لازم تحطه دومين الـ API الحقيقي وقت النشر
- التوكن يُخزَّن في `localStorage` تلقائيًا بعد تسجيل الدخول، ويُرفق مع كل طلب

## البنية

```
src/
  App.jsx              يجمع كل شيء: المصادقة، الشات، القائمة الجانبية
  i18n.js               نصوص عربي/إنجليزي
  hooks/useDirection.js  تبديل RTL/LTR
  lib/
    api.js               إعداد axios + إرفاق التوكن + معالجة 401
    authApi.js            تسجيل / دخول
    chatApi.js             إرسال رسالة شات
    conversationsApi.js     قائمة/تفاصيل المحادثات
  components/            الواجهات (AuthForm, Sidebar, ChatHeader, ChatMessage, ChatComposer...)
```

## الاختبارات

```bash
npm test
```

يغطي AuthForm (تسجيل/دخول) وSidebar (عرض/تعديل/حذف المحادثات).
